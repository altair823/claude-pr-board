# pr-board

Claude Code 패널에 현재 저장소의 열린 PR과 브랜치별 CI 상태를 보여 주는 mod입니다. CI가 오래 걸리거나 러너가 바빠 기다릴 때, 대화를 이어 가면서 어디까지 진행됐는지 볼 수 있습니다.

지금은 Gitea 저장소만 지원합니다. GitHub 저장소에서는 안내만 나옵니다.

## 설치

```
claude plugin marketplace add https://gitea.altair823.xyz/altair823-org/claude-pr-board.git
claude plugin install pr-board@claude-pr-board
```

[tea](https://gitea.com/gitea/tea) CLI가 있어야 하고, `tea login add`로 저장소의 Gitea에 로그인해 두어야 합니다. mod는 `tea api`로 조회만 하고 토큰을 따로 다루지 않습니다.

`/pr-board`로 패널을 엽니다. 직접 닫지 않으면 다음 세션에도 열립니다. 다만 git 저장소가 아니거나 origin 원격이 없는 디렉터리, 아직 지원하지 않는 GitHub 저장소에서는 자동으로 열지 않습니다. 이런 곳에서 `/pr-board`로 열면 이유만 보여 줍니다. git-graph 같은 다른 패널과 함께 쓰면 패널 위쪽의 탭을 클릭해 바꿉니다.

## 화면

| 표시 | 뜻 |
|---|---|
| `#12 로그인 화면` | 열린 PR. PR 끝 커밋에서 돈 CI를 보여 줍니다 |
| `feat/queue  커밋 제목` | PR이 없는 브랜치. CI가 도는 중이거나 하루 안에 돈 브랜치만 나옵니다 |
| `●` | 지금 체크아웃한 브랜치 |
| `▶ test 3분` | 실행 중인 작업과 시작한 뒤 지난 시간 |
| `⏳ release 대기 12분` | 러너를 기다리는 작업과 기다린 시간. 앞 작업이 끝나야 시작하는 작업은 앞 작업이 끝난 뒤부터 셉니다 |
| `✗ test` | 실패한 작업 |
| `✓ 5분 전` | 모든 작업이 성공한 뒤 지난 시간 |
| `승인`, `변경 요청`, `리뷰 대기` | 리뷰어마다 마지막 결정. 새 커밋 전에 남긴 리뷰는 세지 않습니다 |

커서가 있는 줄의 상세가 아래에 나옵니다. PR이면 브랜치, 충돌 여부, 리뷰어별 마지막 리뷰, 작업별 결과가 나옵니다.

패널이 git-graph 같은 다른 탭에 가려져 있으면, CI가 도는 동안 입력창 바로 위에 `CI ▶ #12 3분  ⏳ feat/queue 대기 12분`처럼 요약 한 줄이 나옵니다. PR 탭이 보이는 동안에는 같은 내용이 패널에 있으므로 나오지 않습니다. 기다리던 CI가 끝나거나 새 리뷰 결과가 나오면 알림이 뜹니다. 패널을 닫으면 요약과 알림도 멈춥니다.

상태줄을 쓰지 않는 이유는 Claude Code가 mod의 상태줄 앞에 항상 `⚠ <mod 이름>:`을 붙여서, 정보성 내용도 경고처럼 보이기 때문입니다.

## 조작

패널의 줄을 클릭하거나 `ctrl+x tab`을 누르면 들어가고, `Esc`로 나옵니다.

| 키 | 동작 |
|---|---|
| `↑` `↓` | 줄 이동 |
| `1` | 리뷰 코멘트를 반영해 달라는 문장을 입력창에 넣기(PR 줄) |
| `2` | 실패한 CI를 고쳐 달라는 문장을 입력창에 넣기 |
| `3` | PR을 머지해 달라는 문장을 입력창에 넣기(PR 줄) |
| `r` | 지금 다시 읽기 |

입력창에 넣기만 하고 보내지는 않습니다. 문장을 확인하고 직접 보내면 됩니다.

## 서버 부하

Gitea 서버에 주는 부하를 줄이려고 다음처럼 조회합니다.

- 패널을 연 세션에서만 조회합니다. 패널을 열지 않은 세션은 서버에 요청을 보내지 않습니다.
- 대기 중이거나 실행 중인 CI가 있으면 15초, 없으면 5분마다 다시 읽습니다.
- Claude가 `git push`나 `tea` 명령을 실행하면 바로 다시 읽습니다. `/cd`로 디렉터리를 바꿔도 바로 다시 읽습니다.
- 한 번 읽을 때 PR 목록과 CI 실행 목록을 요청합니다. 리뷰는 PR이 바뀌었을 때만, 작업 목록은 목록에 보이는 실행 가운데 끝나지 않은 것만 다시 요청합니다.
- 같은 저장소를 연 세션이 여러 개면 조회 결과를 `~/.cache/claude-pr-board/<호스트>/<저장소>.json`에 두고 함께 씁니다. 다른 세션이 읽은 결과가 아직 새것이면 서버에 묻지 않고 그 파일을 읽습니다. 그래서 세션이 몇 개든 저장소마다 한 세션분만 조회합니다. push 뒤나 `r`을 누를 때는 파일과 상관없이 서버에서 읽습니다.

두 세션의 조회 시각이 같은 순간에 돌아오면 드물게 둘 다 조회할 수 있습니다.

## 개발

```
claude plugin validate .
claude plugin test .
```

main에 push하면 CI가 시험을 돌리고, 통과하면 `release` 브랜치에 다음 버전을 올리고 태그를 붙입니다(`scripts/ci-release.sh`). 설치본은 `release` 브랜치만 받습니다.
